# common-passwords.txt

The passwords of 12 or more characters from the "100k most used passwords" list of the UK National
Cyber Security Centre (NCSC), as collected in the SecLists project
(<https://github.com/danielmiessler/SecLists>, MIT License, copyright (c) 2018 Daniel Miessler).
Shorter passwords are already refused by the length rule. All entries are lower case and unique, one
per line; the check ignores upper and lower case (LOG-22).

Refreshed by hand when needed. File: `Passwords/Common-Credentials/100k-most-used-passwords-NCSC.txt`.
