Who is responsible

This website is run by {cdi:site.foundation.name}, {cdi:site.foundation.address} (registration number {cdi:site.foundation.registration}). For questions about your data, write to {privacyEmail}.

Which data we use and why

  • Accounts. For members and admins we keep an email address, the role (member, admin or master), the dates the account was made and last used, and the password in a form nobody can read back (a hash). We need this so people can log in and so that we know who may do what.
  • The contact form. The email address, subject and message you send are emailed to the admins of the website, so they can answer you. The message is not stored on the website.
  • Logs and the admin audit trail. The server keeps technical logs, and a record of what admins did (for example adding a user). They help us keep the website safe and find problems. Network addresses are never written to the logs as they are.
  • Files and images. Files that admins put on the website (sheet music, recordings, images in texts) can only contain data that the orchestra is allowed to share. Members' personal data is not in them.

Who receives data

  • Google Cloud hosts the website, the database, the files and the logs, in the European Union (the region europe-west4, Netherlands).
  • Brevo sends the emails of the website (password links and the messages of the contact form). It is a company in the European Union and keeps delivery records for a limited time under its own policy.
  • GitHub keeps the code of the website. It receives no personal data.

We do not sell data, we do not use advertising or tracking services, and the website loads nothing from other companies.

Your rights

You can ask to see your data, to have it corrected or removed, and you can object to how it is used. Write to {privacyEmail}. We answer within one month.

If you think we handle your data wrongly, you can complain to the Dutch Data Protection Authority (Autoriteit Persoonsgegevens), autoriteitpersoonsgegevens.nl.
